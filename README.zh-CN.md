在 Home Assistant 中查看旷远能源网上营业厅（`www.kynyyyt.com`）账号下每个燃气户号的余额、累积用气量、本机统计的日用/月用气量以及充值记录。

> 本集成只调用营业厅的**只读接口**（登录、户号列表、余额查询、充值记录），不会发起充值、缴费、改绑手机号或删除户号等任何写操作。

## 功能

- 支持**多个账号**：每个账号是一个独立配置条目，拥有独立的凭据与设置
- 每个账号可**单独选择显示哪些燃气户号**
- 每个账号可**单独勾选要生成的实体**
- 自动刷新间隔可设（秒），默认 1800，最小 300
- 余额不足阈值可设，低于阈值时 `binary_sensor` 变为 `on`
- 会话失效时自动重新登录一次；密码错误时提示重新验证
- 每个户号各有一个**立即刷新**按钮

## 日用气量 / 月用气量（本机统计）

这两个数值**不来自营业厅接口**，而是由集成读取 Home Assistant 记录器
（[recorder](https://www.home-assistant.io/integrations/recorder/)）中
`累积用气量` 传感器自身的历史数据计算：

| 实体 | 计算方式 |
|---|---|
| 日用气量 | `当前累积用气量 − 今天 00:00 时的累积用气量` |
| 月用气量 | `当前累积用气量 − 本月 1 号 00:00 时的累积用气量` |

基线取该时刻**之前最近一条**记录，因此即便在 09:00 计算，也是从 00:00 起算，
而不是从当天第一次轮询起算。若零点前没有任何记录（刚安装），则退用零点后的第一条记录。
完全查不到历史时实体显示为不可用，而不会给出错误的 `0`。

说明：

- 需要 Home Assistant 自带的 **recorder**（默认开启）
- 刚安装时需跨过一次 00:00 才会有真实数值
- 气表读数回退（换表/清零）时该区间显示不可用，避免出现负数
- 两个实体都带 `source: home_assistant_recorder` 属性，便于核对数据来源

## 实体一览

每个被选中的户号都是独立设备，可生成：

| 实体 | 类型 | 说明 |
|---|---|---|
| 账户余额 | sensor | 单位 CNY，保存 4 位小数（界面显示 2 位） |
| 累积用气量 | sensor | 单位 m³，`total_increasing`，来自营业厅 |
| 日用气量（本机统计） | sensor | 单位 m³，来自 recorder 历史 |
| 月用气量（本机统计） | sensor | 单位 m³，来自 recorder 历史 |
| 通气状态 | binary_sensor | `on` = 已通气 |
| 余额不足 | binary_sensor | 低于阈值时为 `on`（`problem`） |
| 数据时间 | sensor | 营业厅返回的查询时间 |
| 最近充值金额 | sensor | 最新一条充值记录 |
| 最近充值时间 | sensor | 最新一条充值记录 |
| 充值笔数 | sensor | 已读取范围内的记录数量 |
| 立即刷新 | button | 立即查询该户号 |

> 客户名称、详细地址、手机号**不会**生成实体，仅保存在本地配置条目中用于识别户号。

## 安装

### 通过 HACS

1. HACS → 集成 → `⋮` → **自定义存储库**
2. 填入 `https://github.com/moelolinet/kuangyuan_gas`，类别选择 **Integration**
3. 搜索 `Kuangyuan Gas` 并安装
4. 重启 Home Assistant

### 手动安装

把 `custom_components/kuangyuan_gas` 复制到 Home Assistant 配置目录下的
`custom_components/` 中，然后重启。

## 配置

设置 → 设备与服务 → **添加集成** → 搜索 `Kuangyuan Gas`：

1. 输入营业厅登录手机号与密码（可自定义营业厅地址）
2. 选择要显示的户号
3. 选择要启用的实体
4. 设置刷新间隔与余额不足阈值

该配置条目（中枢）的名称默认就是登录账号。

### 多个账号

再次添加集成即可。每个账号都是独立条目，凭据、户号选择、刷新间隔与登录会话完全隔离。

### 修改设置

集成卡片 → **配置**。可随时调整户号、实体与刷新间隔；保存后自动重载，
不再需要的实体会被一并清理。

## 刷新间隔

营业厅前面有云 WAF，会对频繁访问限流。集成会串行发送请求并加入间隔，
建议 **≥ 600 秒**，最低允许 300 秒。

历史基线每天（每月）只读取一次，因此提高轮询频率不会增加数据库压力。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 提示「手机号或密码不正确」 | 密码区分大小写；网页能登录但集成不能时，请检查是否启用了短信二次验证 |
| 提示「无法连接营业厅」 | 网络问题或被限流，稍后重试 |
| 实体不可用 | 该户号本次查询失败，会保留上次数值并写入 `last_error` 属性 |
| 日用/月用气量不可用 | 未启用 recorder，或历史数据不足 |
| 反复要求重新验证 | 密码已在营业厅修改，或账号被限制 |
